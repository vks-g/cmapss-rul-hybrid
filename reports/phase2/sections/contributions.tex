\section*{Author Contributions}
All code, notebooks, results and report sections are in the project
repository, where each file's history shows its author, and every change was
reviewed through a pull request.

\item \textbf{Gokul VKS} (lead): the shared trainer and config-driven runs; the

\item \textbf{Mohammad Affan Anas}: the PyTorch setup; the CI and pull-request

  regularization section; the Phase~2 README and architecture diagrams; the
